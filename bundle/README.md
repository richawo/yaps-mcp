# Yaps

Transcribe recordings, create subtitles and meeting transcripts, translate,
extract audio from video, and use optional private Markdown memory from Claude
Desktop.

1. Download and open Yaps from https://yaps.ai/download.
2. Sign in to Yaps. New users need an account; gated features require an active free trial or Yaps Pro. The connector is free.
3. Install this MCP Bundle.
4. For Memory, allow Claude Desktop in Yaps → Settings → Agent Access.

The connector processes supported workflows on your computer, refuses to replace existing output files, and does not include an API key, hosted proxy, or analytics client.

Approve model downloads before they start. Requested results can enter Claude's
context. Memory reads and writes require separate Agent Access permissions.

## Privacy Policy

See https://www.yaps.ai/privacy. The connector has no hosted relay; the requesting
MCP client receives tool results. Local files remain until the user deletes
them; temporary meeting audio is deleted after the tool call. Contact
support@yaps.ai with privacy questions.
