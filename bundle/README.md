# Yaps

Use local Yaps Memory, transcription, meeting transcripts, subtitles, translation, and video-to-audio conversion from Claude Desktop.

1. Download and open Yaps from https://yaps.ai/download.
2. Sign in and activate an available free trial or Yaps Pro.
3. Install this MCP Bundle.
4. For Memory, allow Claude Desktop in Yaps → Settings → Agent Access.

The connector processes supported workflows on your computer, refuses to replace existing output files, and does not include an API key, hosted proxy, or analytics client.

## Privacy Policy

See https://www.yaps.ai/privacy. The connector does not collect or share prompts, notes, media, or generated files. Local files remain until the user deletes them; temporary meeting audio is deleted after the tool call. Contact support@yaps.ai with privacy questions.
