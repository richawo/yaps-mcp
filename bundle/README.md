# Yaps Local Memory

This MCP Bundle launches the native local server included with the Yaps desktop app.

1. Download Yaps from https://yaps.ai/download.
2. In Yaps, open Settings → General → Local AI integrations.
3. Connect this client. Yaps starts read-only; enable writes separately only if you need them.

The bundle does not contain an API key, hosted proxy, analytics client, or independent copy of your vault. See https://github.com/richawo/yaps-mcp for documentation and source.
