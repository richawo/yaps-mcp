# Connectors Directory listing

## Name

Yaps

## Tagline

Local transcription, subtitles, translation, audio, and private memory

## Description

Turn recordings into transcripts, speaker-labelled meeting transcripts, and SRT
subtitles. Translate text and files, extract audio from video, and optionally
search or update private Markdown notes.

Try: "Transcribe this product demo and save a separate text file."

Install Yaps on the same computer and sign in. New users need a Yaps account.
The connector is free; gated features require an active free trial or Yaps Pro.
No user API key is needed. Approve any required model download before it starts.

Processing happens on your computer. Requested results can enter Claude's
context. Memory reads and writes need separate Agent Access permissions.
Existing output files are preserved.

## Primary use cases

1. Transcribe a recording into a new text file.
2. Create a speaker-labelled transcript from a meeting or interview.
3. Generate timestamped SRT subtitles.
4. Translate text, Markdown, text files, or SRT subtitles locally.
5. Extract MP3, WAV, or M4A audio from a video.
6. Search and cite private local Yaps notes.

## Setup requirements

1. Download and open Yaps.
2. Sign in to Yaps; gated features need an active free trial or Yaps Pro.
3. Install the MCP Bundle in Claude Desktop.
4. For Memory, allow Claude Desktop in Yaps → Settings → Agent Access.
